# 🚀 STARTUP GUIDE - Animal Crossing CE

## 🎬 FIRST TIME PLAYING?

### What to Expect:
1. **Loading Screen appears** - Shows NookPlane while assets load (30-60 seconds)
2. **Press START button** - When "PRESS TO START" appears
3. **Loading screen fades** - Game world visible, camera active
4. **Keybind hint appears** - Bottom-right corner (after 1 second delay)
5. **You can move!** - WASD to walk, camera follows smoothly

### Your First 5 Minutes:
1. **Look at keybinds** (bottom-right corner box)
2. **Press E** - Open inventory (should see 10 empty slots)
3. **Press B** - Open item browser (add items to test)
4. **Press C** - Open crafting menu
5. **Press F1** - See all keybinds and help

## 🐛 TROUBLESHOOTING

### "I don't see the keybind hint!"
- Look in **bottom-right corner**
- It might be minimized - look for a small box with **+** button
- Press **F1** to bring up full guide
- It appears 1 second after loading screen closes

### "I can't open inventory!"
- Press **E** key
- Make sure you're not typing in chat
- Click on game world first (to remove focus from UI)
- Check console (F9) for errors

### "Game loaded but I see errors in console"
- Most errors are just warnings (safe to ignore)
- Look for **"infinite yield"** - these matter
- Check **ERROR_FIXES_AUDIT.md** for known issues

### "Loading screen stuck"
- Assets are still loading (sprite sheet is large)
- Wait for **"PRESS TO START"** button to appear
- Should take 30-60 seconds max
- If > 2 minutes, check internet connection

### "Camera feels weird"
- Camera is Animal Crossing style (high angle, smooth)
- Use **mouse** to rotate camera
- Use **2 fingers** on touchpad to pan
- This is intentional ACNH-style camera!

### "Controls don't work"
- Click on game world (remove focus from Roblox UI)
- Press **ESC** to close any open menus
- Make sure you're in Studio Play mode (F5)
- Check if another GUI has stolen focus

## 🎯 GETTING STARTED TUTORIAL

### Step 1: Get Some Items (Debug Mode)
1. Press **B** (Item Browser)
2. Scroll through items
3. Click items to add to inventory
4. Press **E** to check inventory
5. You should see items in slots!

### Step 2: Try Crafting
1. Press **C** (Crafting Menu)
2. Browse recipes
3. Click a recipe (if you have materials)
4. Item crafts instantly (debug mode)
5. Check inventory to see result

### Step 3: Explore Controls
1. Press **P** (NookPhone) - Not fully implemented yet
2. Press **T** (Tools) - Quick tool selector
3. Press **`** (Menu) - Settings and options
4. Press **F1** (Guide) - Full keybind reference

### Step 4: Understand the UI
- **Bottom-right**: Essential keybinds (minimizes after 30s)
- **Top-right**: Currency display (Bells/Miles)
- **Press F1**: Full interactive keybind guide
- **ESC or `**: Close most menus
