## 🎨 VISUAL INDICATORS

- **Bottom-right corner**: Persistent control hints (auto-minimizes after 30s)

- **Hover over buttons**: Most UI elements show tooltips

## 💡 TIPS

1. **The controls overlay doesn't interfere with Roblox UI** - It's positioned carefully in the corner
2. **Press F1 anytime** - Brings up the full guide with all keybinds
3. **Game Menu (`)** - Access settings, volume, graphics, etc.
4. **Minimize the hint** - Click the `-` button in the corner overlay
5. **Loading screen** - Shows NookPlane asset while game loads in background

## 🚀 GETTING STARTED

1. **Press the START button** on loading screen when assets are loaded
2. **Controls appear bottom-right** - Reference the essential keys
3. **Press E** - Open your inventory
4. **Press B** (debug) - Browse all items and add to inventory for testing
5. **Press C** - Open crafting menu
6. **Press F1** - See this full guide in-game

## 🐛 TROUBLESHOOTING

**Q: I can't see the controls!**
- A: Look in the bottom-right corner - there's a cream-colored box with keybinds
- A: Press F1 to bring up the full guide overlay

**Q: Keybind not working?**
- A: Make sure you're not typing in chat or another text box
- A: Press ESC to close any open menus first
- A: Check if another GUI has focus (click on the game world first)

**Q: Too many UIs overlapping?**
- A: Press ` (tilde) for Game Menu, most GUIs are mutually exclusive
- A: Press ESC to close current GUI
- A: Minimize the corner hint with the `-` button

**Q: Want to test items without grinding?**
- A: Press **B** to open Item Browser
- A: Click any item to add it to your inventory instantly
- A: This is a debug feature for testing
